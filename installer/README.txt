Claude Limits — Windows 11 Widget
==================================

Install
-------
1. Run ClaudeWidgetSetup.exe and approve the UAC prompt.
2. Open the Widgets board (Win+W), click Add widgets, and add "Claude Limits".

You may also need "Install untrusted apps" / Developer sideloading enabled:
Settings > Privacy & security > For developers.

Uninstall
---------
Use Settings > Apps > Installed apps > "Claude Limits" > Uninstall
(or Control Panel > Programs and Features).

This removes both the app and the certificate that Setup trusted for it —
nothing is left behind on your machine.
